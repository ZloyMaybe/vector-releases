# Вектор

Голосовой ассистент для Windows: открывает и закрывает программы, управляет музыкой и громкостью,
ставит таймеры и напоминания, говорит время — голосом, по слову «Вектор» или по кнопке.

## Установка

1. Скачай `Vector-Setup-….exe` из последнего [релиза](../../releases/latest).
2. Запусти и нажми «Установить». Права администратора не нужны.
   Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом
   случае»; если «Фильтр SmartScreen сейчас недоступен» — «Запустить». Это из-за того, что у Векторa
   пока нет платного сертификата Microsoft.
3. При первом запуске Вектор сам докачает распознавание речи и голос (от 0,7 до 3 ГБ, зависит от видеокарты).

Обновления Вектор проверяет сам и предложит установить новую версию прямо в окне.
Каждое обновление подписано — подменённый установщик Вектор не примет.

## Требования

Windows 10/11 x64, микрофон. С видеокартой NVIDIA распознавание точнее и быстрее.
